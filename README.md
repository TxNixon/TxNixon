### A little context

I'm **Admojo (Joe)**, a business owner and self-taught programmer in **Surabaya, Indonesia**. I run **SL SBY** and enjoy building tools that make everyday work simpler.

My favorite projects start with a real operational problem: a manual handover, a repetitive task, or information that should flow automatically. I'm learning JavaScript, Python, and full-stack development by turning those problems into working software.

**Currently exploring:** workflow automation, practical AI integrations, and better connections between business systems. Outside the build loop: finance, markets, and family time.
